# Osinara v0.11.0

Основной агент переведён с прямого DeepSeek endpoint на существующий CLIProxyAPI/CPA с пулом OpenCode Go.

## CPA как основной model gateway

- Основная модель теперь запрашивается как `opencode-go-deepseek-v4-flash` через OpenAI-compatible CPA endpoint.
- CPA остаётся на отдельном сервере и доступен Osinara только внутри Tailscale по HTTPS.
- На Osinara хранится отдельный downstream bearer key; OpenCode Go credentials, rotation и retry остаются внутри CPA.
- Thinking mode `high`, разделение `reasoning_content` и multi-round tool continuation сохраняются без изменения agent loop.

## Эксплуатационные границы

- Прямой `DEEPSEEK_API_KEY` больше не требуется как upstream credential; deployment variable с прежним именем передаёт отдельный CPA bearer key до следующей migration схемы окружения.
- Groq Whisper остаётся отдельным прямым маршрутом и не проходит через CPA.
- Vision остаётся отключённым для выбранной DeepSeek-модели.
- Текущий compatibility `cli-proxy-api` service остаётся в six-image deployment graph и не участвует в основном model route.
