# v0.72.0 — гостю можно выдать ваши скиллы и ключи API

Владелец может открыть гостю выбранные скиллы из библиотеки семьи и доступ к сохранённым ключам API — поштучно,
по умолчанию гостю не выдано ничего (#474). Раньше гость получал только встроенные скиллы и свои собственные, а ключи
API семьи до его песочницы не доходили вообще.

Одна миграция: 154 (у записи гостя появляется список выданных скиллов; у существующих гостей он пустой). Применяется
мгновенно. Переиндексация памяти не нужна, новых секретов и переменных окружения нет, ручных шагов после выкатки нет.

## Что изменилось для пользователя

**Выдать скилл.** Напишите агенту в личке «выдай Пете скилл image-gen» и подтвердите кнопкой — на карточке видно
гостя и список ваших скиллов, которые у него будут. Скилл появляется у гостя со следующего сообщения. Перед выдачей
агент предупредит: гость увидит текст и файлы скилла и сможет их скопировать, а скилл, которому нужны ваши логины,
токены, установленные у вас программы или домашние устройства, у гостя не заработает. Гостю о выдаче не сообщается.

**Выдать ключ.** «Дай Пете доступ к ключу imagegen» — тоже с кнопкой, на карточке «Кому: гость Петя». Со следующей
команды в песочнице гостя есть `IMAGEGEN_API_KEY` и `IMAGEGEN_BASE_URL`. Самого ключа гость не видит — только
заглушку, а настоящий ключ подставляет сервер. При этом гость может у сервиса всё, что разрешает сам ключ, как и
внешняя группа с выданным ключом. Если выданному скиллу нужен ключ, которого у гостя нет, агент сразу предложит
выдать и его.

**Посмотреть и забрать.** «Покажи гостей» показывает у каждого гостя выданные скиллы и ключи с числом запросов по
каждому ключу; «Покажи ключи» — гостя отдельной строкой. «Забери у Пети скилл / ключ» — со следующего сообщения
скилла нет, а запросы с ключом отклоняются. Лимитов расхода нет, только учёт запросов.

**Изменения в библиотеке.** Новая версия выданного скилла приходит гостю со следующего сообщения. Удалённый скилл
пропадает у гостя, и новый скилл с тем же именем сам ему не выдастся. Если выданный гостю скилл изменит или удалит
другой член семьи, владелец получит уведомление — как сейчас для скиллов внешних групп.

**Гостя убрали и вернули.** Убранный гость сразу перестаёт тратить ваши ключи. Вернулся по новой ссылке — выданные
скиллы и ключи снова при нём, как и выключенное.

**Настройка гостя стала аккуратнее.** «Отключи Пете браузер» меняет только список выключенного и не трогает
выданное — и наоборот.

**Исправлено:** карточка выдачи ключа подписывала любого получателя, кроме внешней группы, как «вся семья».

## Надёжность и безопасность

- Ключ, выданный гостю, сервер принимает только из отдельной сети песочницы этого гостя; из песочниц семьи и других
  гостей его заглушка не работает. Значение ключа гостю не передаётся.
- Гость не может изменить, выключить или удалить выданный скилл: он лежит в вашей библиотеке, а не в его. Сохранить
  свой скилл под именем выданного гость тоже не может (`AGENT_SKILL_NAME_TAKEN`).
- Выдать скилл с именем, которое уже занято своим скиллом гостя, нельзя (`AGENT_GUEST_SKILL_NAME_CONFLICT`).
- Если при удалении гостя сервер не успел закрыть его ключи, владелец видит `AGENT_GUEST_KEYS_NOT_CLOSED` и повторяет
  удаление. Если ключи не вернулись вместе с гостем, повторная выдача ключа применяет список заново.

## Что не входит

- Доступ гостя к вашей домашней сети и устройствам.
- Ограничение выданного ключа отдельными адресами сервиса.
- Лимит расхода ключа на гостя.
- Свои ключи API гостя.
