# v0.47.1 — список и версии скиллов семьи снова открываются

Одна миграция (137): удаляется неиспользуемая колонка `agent_session_state.announced_skills`.
**Переиндексация памяти не нужна.** Правила мониторинга не меняются.

## Что изменилось для пользователя

**«Какие скиллы есть в семье» и история версий скилла снова работают.** В v0.47.0 агент получал
вместо списка техническую ошибку:

- история версий скилла («покажи версии doc-signing», «откати на версию 2») не открывалась ни разу с
  выкатки v0.47.0;
- список скиллов семьи перестал открываться у всех членов семьи после первой загрузки семейного скилла
  (18.10 в 23:40 UTC). Без исправления так продолжалось бы 30 дней — столько учитывается история
  загрузок.

Причина — даты в ответе инструмента `manage_skill`: ядро не принимает их в том виде, в каком их
отдавала база. Теперь даты версий и последней загрузки передаются строкой времени. Сами скиллы, их
включение и работа всё это время не ломались.

## Для владельца и дежурного

- Убран мёртвый код, оставшийся после v0.47.0:
  - ядро на каждом ходе записывало список скиллов в отдельную колонку сессии, но никто её не читал:
    тот же список и так хранится в каждом ходе (`agent_turns.prepared`). Запись и колонка удалены
    (миграция 137);
  - подсказки веток памяти по загруженному скиллу: единственный скилл с такой подсказкой, `t-invest`,
    убран в v0.47.0. Ветки памяти по-прежнему поднимаются по найденным записям и по близости названия.
- **Откат:** после миграции 137 образ v0.47.0 запускать нельзя — он пишет в удалённую колонку на каждом
  ходе. Вернуться назад можно только восстановлением резервной копии, снятой выкаткой.
- В песочнице владельца удалена папка `~/.config/tinvest/` с токенами T-Invest: без скилла они не
  использовались. Отозвать сами токены можно только в личном кабинете Т-Банка.
