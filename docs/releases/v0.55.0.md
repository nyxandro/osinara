# v0.55.0 — оформленные напоминания, сворачивание решает агент, промпт легче на шестую часть

Миграций нет, переиндексация памяти не нужна, новых секретов нет, правила мониторинга не меняются.

## Что изменилось для пользователя

**Напоминания оформлены так же, как ответы в чате.** Раньше напоминание приходило простым текстом.
Теперь:
- текст с разметкой приходит оформленным сообщением под жирным заголовком — со списками, жирным,
  ссылками;
- картинка или файл из рабочей папки приходит прямо внутри напоминания, например фото списка покупок
  или PDF билета;
- напоминание никогда не сворачивается под «Полный ответ»;
- простое напоминание без разметки и файлов приходит обычным сообщением, как раньше.

Если файл к моменту напоминания приложить нельзя (его удалили, он стал слишком большим), напоминание
всё равно приходит вовремя, а на месте файла видна строка с причиной и кодом. Кнопки под напоминанием
с файлами работают полностью.

**Сворачивать длинный ответ решает агент.** Раньше код сам прятал ответ под «Полный ответ», если в
нём было больше двух абзацев или около 600 знаков, даже когда агент нарочно оставил его открытым.
Теперь ответ приходит ровно таким, каким его сверстал агент:
- короткий ответ — до двух-трёх абзацев, около десяти строк, без таблицы или длинного списка —
  остаётся открытым;
- длинный — суть снаружи, подробности под раскрывающимся блоком;
- вопрос, на который отвечают кнопки, всегда виден.

Если агент ошибся в разметке раскрывающегося блока, блок показывается текстом, а не ломает сообщение.

**Каждый ход агент читает меньше инструкций.** Редкие процедуры — голосовые ответы, сценарии и мониторы,
администрирование групп, напоминания во внешней группе, делегирование задач — вынесены из постоянной
инструкции в служебные скиллы. Агент подгружает такую процедуру только в том ходе, где она нужна.
Каждый ход модель читает меньше текста:

| Чат | Было | Стало |
| --- | --- | --- |
| Личный | 129 тыс. знаков | 108 тыс. (−16%) |
| Семейная группа | 132 тыс. | 116 тыс. (−12%) |
| Сценарий по расписанию | 109 тыс. | 92 тыс. (−15%) |
| Внешняя группа | 118 тыс. | 106 тыс. (−10%) |

Правила, которые раньше повторялись в нескольких местах, теперь живут в одном.

**Агент сам исправляет неверный вызов настроек.** Если агент ошибся в вызове напоминаний, сценариев,
настроек группы, приглашений в семью или уведомлений, инструмент отвечает готовым образцом
правильного вызова. Агент исправляется со второй попытки, а не бросает дело. Раньше неверный вызов
приглашения или настроек группы мог оборвать ход целиком, а неверный вызов сценария внешней группы
выглядел для агента как окончательный отказ.

## Безопасность

- **Файлы в напоминаниях проверяются по правам чата, куда придёт напоминание.** Личное напоминание
  берёт файлы из личной и семейной папок, семейное — только из семейной, напоминание внешней
  группы — только из папки группы. Права проверяются при создании напоминания и ещё раз при
  отправке.
- **Служебные скиллы выдаются только там, где есть их инструмент.** Скилл администрирования групп не
  появится в ходе, где нет управления группами. Внешняя группа получает только свои служебные
  скиллы, семейные процедуры ей недоступны.

## Для владельца и дежурного

- **Код журнала заменён.** `AGENT_REMINDER_BUTTONS_REJECTED` больше не пишется, вместо него
  `AGENT_REMINDER_RICH_MESSAGE_REJECTED`: Telegram отказал оформленному напоминанию. В таком случае
  напоминание один раз уходит обычным текстом без кнопок; неясный исход не повторяется.
- **Скиллы семьи пишутся по-английски.** Инструкция по созданию скиллов требовала писать их
  по-русски, это была ошибка. Новые скиллы целиком на английском, а описание — одна короткая строка о
  том, когда скилл загружать. Готовые тексты, которые скилл выдаёт людям дословно, остаются на своём
  языке.
- **Во внешней группе инструмент `load_skill` теперь есть всегда.** Какие скиллы он загрузит, решают
  список скиллов группы и служебные скиллы хода.
- **Отказ «похожая нить» стал подсказкой.** Когда агент пытается завести нить памяти, похожую на уже
  существующую, он получает список подходящих нитей и следующий шаг, а не общую ошибку.
- **Что смотреть в журнале после выкатки:**
  - `AGENT_REMINDER_RICH_MESSAGE_REJECTED` — напоминание ушло простым текстом;
  - строки «⚠️ Не удалось приложить» в напоминаниях — файл пропал или не прошёл проверку;
  - вызовы `load_skill` со служебными скиллами `voice-replies`, `schedules`, `group-admin`,
    `group-reminders`, `delegation` — агент подгружает вынесенные процедуры.
