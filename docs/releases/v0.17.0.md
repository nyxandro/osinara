# Osinara v0.17.0

Minor-релиз добавляет управляемую генерацию изображений через действующую Codex-подписку без
отдельного OpenAI API key и без обхода application authorization.

## Image Generation

- Интерактивный root-agent создаёт ровно одно WebP через `gpt-image-2`, сохраняет файл по
  детерминированному operation-specific пути в authorized personal, family или group workspace и сразу отправляет его в
  текущий Telegram-чат как photo.
- Dynamic skill `imagegen` задаёт reviewed prompt workflow и появляется только вместе с реально
  доступным `generate_image`; scheduled turns и subagents не получают ни skill, ни tool.
- Feature включается только при активном `codex-subscription`. При любом другом provider tool и skill
  отсутствуют во всех режимах, а `generate_image` пропадает из owner-managed grant contract:
  `manage_telegram_group` и registration отклоняют его с отдельным объяснением, поэтому включить
  capability нельзя. Grant, сохранённый под Codex, остаётся в PostgreSQL, показывается в status как
  `unavailableConfiguredTools` и снова начинает действовать только после возврата provider.

## External Group Authorization

- `generate_image` добавлен в полный owner-managed external capability catalog.
- Владелец включает или выключает его через `manage_telegram_group.update_policy` в личном чате;
  операция сохраняет существующий HITL и повторную проверку актуальной owner-role в PostgreSQL.
- Step-scoped descriptor пересекает verified snapshot с live policy, а execute ещё раз проверяет
  текущий grant перед billable provider call. Отозванное право не сохраняется до конца старой сессии.

## Billing And Delivery Safety

- Migration `076_image_generation_operations.sql` добавляет durable ledger: call ID резервируется до
  обращения к provider, completed result replay не генерирует изображение повторно, а input drift
  блокируется.
- Transport error, timeout, 5xx, повреждённый success и неподтверждённое сохранение становятся
  terminal ambiguous. Автоматический retry запрещён, потому что лимит подписки уже мог быть списан.
- Подтверждённые bytes проходят WebP boundary, сохраняются через workspace repository и доставляются
  существующим exact-once `send_workspace_file` с Telegram delivery ledger.
- CLIProxy запускается с `disable-image-generation: chat`: provider-native hidden tool выключен для
  обычных model calls, а контролируемый `/v1/images/generations` остаётся доступен приложению.

## Проверка

- Unit contracts покрывают exact HTTP payload, WebP validation, no-retry semantics, provider gate,
  dynamic skill visibility, external live revocation и отсутствие capability в scheduled/subagent
  surfaces.
- Database integration contracts покрывают reservation, completed replay, input mismatch и terminal
  ambiguous state; migration ledger fixture включает migration 076.
- Полный Docker Compose CI проверяет unit/integration contracts, typecheck, Eve build и runtime
  composition перед merge.
