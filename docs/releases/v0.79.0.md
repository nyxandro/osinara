# v0.79.0 — фоновая задача с браузером больше не ломает песочницу чата

Исправление фоновых задач (#529). Новых функций нет.

Миграций нет, переиндексация памяти не нужна, ручных шагов после выкатки нет: пакет наблюдения не менялся.

## Что изменилось для пользователя

- **Фоновая задача с браузером не мешает другим задачам и основному агенту (#529).** Все ходы чата — основной
  агент и его фоновые задачи — работают в одной песочнице. Раньше в ней помещался только один браузер: когда задача
  открывала свой рядом с браузером основного агента, команды всех ходов чата время от времени отказывали, задача теряла
  часть работы и могла закончиться без результата. Теперь два браузера помещаются.
- **Браузер задачи закрывается, когда задача закончилась.** Раньше он мог остаться и ещё час держать четверть памяти
  сервера; в эти минуты бот замедлялся и на секунды терял базу. Пока задача ждёт вашего ответа на вопрос, её браузер
  закрывается сам через 10 минут простоя, как и раньше.
- **Если песочница всё же переполнена, агент понимает причину.** Вместо безликого «сбой» он получает объяснение и
  закрывает лишние сессии браузера, а не открывает новые.

## Внутри и для владельца

- Предел мест под процессы в песочнице — 512 вместо 256 (один браузер занимает ~170–200, два — ~345). Память песочницы
  прежняя, 2 ГБ: если два тяжёлых сайта не поместятся, система закроет самую тяжёлую вкладку, а не команды.
- Песочницы чатов пересоздаются с новым пределом при первом обращении после выкатки; файлы остаются на месте.
- Инструкция фоновой задачи: одна сессия браузера, новые страницы — вкладками, закрыть, когда не нужна.

## Наблюдение

- `AGENT_SANDBOX_PROCESS_LIMIT_REACHED` — в песочнице кончилось место под процессы: строкой в выводе команды, кодом
  ответа раннера 503 у файловых операций, кодом ошибки инструмента. Остаётся ошибкой в счёте `OsinaraErrorBurst`.
- `AGENT_BACKGROUND_TASK_BROWSER_CLOSE_FAILED` — браузер закончившейся задачи закрыть не удалось; итог задачи не
  меняется, браузер закроется сам по простою.

## Выкатка и установка

- Ручных шагов нет.
