# v0.78.0 — права перепроверяются при доводке оборванного хода, фоновая задача видит заметки чата

Второй выпуск «надёжности» (план `docs/plans/[18.11.2026]-reliability-batch.md`) и исправление фоновых задач.
Новых функций нет.

Миграций нет, переиндексация памяти не нужна, ручных шагов после выкатки нет: пакет наблюдения не менялся.

## Что изменилось для пользователя

- **Фоновая задача видит заметки чата (#530).** Раньше задача работала без оперативной инструкции владельца —
  как с ним говорить, текущие обстоятельства, открытые дела — и могла сделать работу не так, как просили в
  заметках (формат, язык, ограничения). Теперь задача читает заметки своего чата, как отчёт о ней и пробуждения.
  Менять заметки задача по-прежнему не может.

## Внутри и для владельца

- **Оборванный ход доводится, только если права человека и чата ещё действуют (#542).** Если ход бота оборвался
  (перезапуск, выкатка, падение процесса), ядро доводит его до конца. Раньше права при этом не перепроверялись:
  если в эти минуты человека убрали из семьи, отозвали гостя или отключили группу, ответ всё равно ушёл бы в чат.
  Теперь перед доводкой приложение заново проверяет доступ: человек в семье, гость не отозван, группа подключена,
  во внешней группе — её режим доступа. Нет доступа — ход закрывается без вызова модели и без сообщения в чат.
  Ходы проверки памяти, фоновых задач и подагентов не меняются: у них своя перепроверка.
- **Меньше ложных строк ошибок.** Каждый ход фоновой задачи писал `AGENT_BEHAVIOR_PREFERENCE_UNAVAILABLE`
  в счёт всплеска `OsinaraErrorBurst`; теперь этих строк нет.

## Наблюдение

- Оборванный ход без доступа закрывается с кодом `AGENT_TURN_ACCESS_REVOKED`. Это ожидаемый исход, уведомления
  владельцу о нём нет.
- Новые строки журнала: `AGENT_TURN_RESUME_ACCESS_UNREADABLE` — права прочитать не удалось, ход ждёт следующего
  прохода восстановления через минуту; `AGENT_TURN_RESUME_REVOKE_FAILED` — ход без доступа не удалось закрыть,
  остальные ходы восстанавливаются дальше.

## Выкатка и установка

- Ручных шагов нет.
