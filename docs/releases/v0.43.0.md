# v0.43.0 — инструменты агента: понятные описания и подтверждение публикаций в группу

Миграций нет. **Переиндексация памяти не нужна.** Правила мониторинга не меняются.

## Что изменилось для пользователя

**Публикации во внешнюю группу — только по кнопке владельца.** Автоматизация, которая по расписанию
публикует результат во внешнюю Telegram-группу, раньше создавалась и менялась без подтверждения. Этот
инструмент есть и у дочернего агента, который читает непроверенные веб-страницы. Инструкция,
спрятанная на такой странице, теоретически могла настроить отправку данных разговора в группу.
Теперь создание и изменение такой автоматизации Osinara показывает владельцу карточкой с кнопками.
В карточке названы группа, название, время первого запуска, повторение словами («каждую неделю по
дням: пн»), исходная просьба и текст сценария, дополнительные инструменты, за сколько дней читается
история группы и лимит запусков. При изменении карточка называет, какую автоматизацию и в какой
группе меняют, и показывает только меняющиеся поля, включая снятие лимитов. Просмотр, пауза,
возобновление, запуск сейчас и удаление по-прежнему проходят без кнопки.

**Память во внешних группах сохраняется с первой попытки.** За 3–15 октября 9 из 12 отклонённых
вызовов `remember` случились по одной причине: модель не указывала область памяти там, где
допустима только память группы. Теперь эту область сервер подставляет сам. В тихой проверке памяти
так же подставляются два других поля с единственным допустимым значением, а номер исходного
сообщения модель видит как обязательный заранее, а не узнаёт из отказа.

**Агент не отказывается делать заметки и отчёты файлами.** Описания файловых инструментов достались
от агента для программистов и содержали правила вроде «никогда не создавай .md» и «без эмодзи».
Теперь они написаны для семейного ассистента: какие папки доступны, сколько длится команда
(2 минуты), когда обрезается вывод (2000 строк или 50 КБ, остаётся конец).

**Описания инструментов короче и понятнее модели.** Блок описаний в личном чате уменьшился с 60,6
до 57,9 тыс. символов, первый запрос разговора — с 39,0 до 37,8 тыс. токенов:

- у сценариев по расписанию назначение стоит первой фразой, поля описаны, правило про лимит
  запусков перенесено в само поле;
- формат вызова сценариев и напоминаний больше не продублирован в системном промпте;
- из описания управления группами убран устаревающий список скиллов: актуальный отдаёт `status`;
- даты в истории группы и в журнале отправок проверяются так же строго, но без шаблона на 300
  символов в каждом поле;
- инструменты «нитей», профиля и выгрузки памяти описаны словами «когда нужен и что вернёт», а
  не внутренним жаргоном.

Проверка на 26 типовых просьбах к боевой модели, по 3 раза каждая: до изменений нужный инструмент
выбран в 73 случаях из 78, после — в 77 из 78.

## Для владельца и дежурного

- Карточка подтверждения автоматизации внешней группы — новая. Её отклонение завершает действие
  так же, как у остальных подтверждений. Уже созданные автоматизации продолжают работать без
  повторного подтверждения: кнопка нужна только при создании и изменении.
- `subject` у `remember`, присланный провайдером строкой JSON, по-прежнему принимается и
  проверяется той же строгой схемой; меняется только то, что модель больше не читает шаблон в 940
  символов.
- Полный аудит инструментов агента — `docs/plans/agent-tools-audit.md`.
