# v0.21.13: агент сам решает, как ответить в группе

## Молчание стало штатным исходом хода

Устранена причина сообщений вида «это не ко мне» и «вы меня просто упомянули, не вмешиваюсь».
Раньше у модели в группе было только два разрешённых исхода: текст или реакция. Когда обращения
не было, она возвращала пустой ответ, а Eve считала пустой ответ сбоем и один раз требовала
ответить. Модель подчинялась и писала объяснение, почему молчит, прямо в чат.

Теперь у каждого группового хода четыре равноправных исхода: промолчать, поставить реакцию,
ответить одним сообщением, ответить несколькими через паузу. Молчание модель выражает штатным
маркером Eve `<eve-empty-delivery/>`: канал ничего не отправляет, шаг не попадает в историю,
повторный вызов модели не выполняется. Если набор реакций чата неизвестен, вместо реакции
агент молчит, а не пишет текст. Правила одинаковы для семейной и внешней группы и выдаются только
живому корневому ходу: запланированный запуск и дочерний агент их не получают. Поведение личного
чата не меняется.

Каждый молчаливый ход пишется в лог записью `AGENT_TELEGRAM_SILENT_TURN` с типом чата, типом
группы и причиной пробуждения. Текст сообщений и идентификаторы участников в запись не попадают.

Маркер не входит в публичный API Eve. Установка закрепляет его контракт в рантайме Eve `0.40.0`
и останавливается при расхождении, чтобы обновление фреймворка не отключило молчание незаметно.

## Модель знает, почему её разбудили

Блок текущего сообщения группы получил поле `triggeredBy`: `mention` (написан @username бота),
`reply_to_agent` (ответ на реплику агента) или `name_in_text` (имя без @username). При нескольких
сигналах побеждает @mention, затем ответ на реплику. Поле описывает, как сработал технический
триггер, и не решает за модель, обращались ли к ней: имя без @username одинаково покрывает
«Осинара, посчитай» и «Осинара вчера сказала», и различать их по тексту обязана модель.
Обращение по имени с вопросом или просьбой остаётся полноценным обращением, равноценным @mention.

Личный чат прямой по определению и поля не получает. Конверт отклоняет групповой ход без причины
и личный чат с причиной как повреждённый ввод.

## Вопрос участнику

В группе агент может задать вопрос конкретному участнику по имени или @username ровно в двух
случаях: без его ответа нельзя выполнить просьбу, либо у этого человека есть сведения или
решение, без которых текущее обращение не продвинуть. Добивка через паузу может быть репликой
другому участнику. Вопрос ради поддержания разговора и вступление в чужую беседу остаются
запрещёнными.

## Проверка

Сквозной прогон в Docker получил обращение по имени в третьем лице в семейной группе: модель
отвечает маркером, чат не получает ни одного сообщения, вызов модели выполняется один раз,
очередь входящих сообщений завершает запись штатно. Для обращений через @mention во внешней группе
проверяется, что модель видит `triggeredBy: mention`.
