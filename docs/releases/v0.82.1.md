# v0.82.1 — повтор выпуска v0.82.0: обновление ставится быстрее

Содержимое то же, что у v0.82.0 (#577, PR #578); нового кода нет. Выкатка v0.82.0 25.11.2026 в 02:40 UTC не
началась: GitHub API несколько минут отвечал 504 на запрос описания релиза, и сервер отказал на первом шаге,
до остановки бота — работала прежняя версия. Одну версию дважды не предлагают, поэтому тот же выпуск идёт под
новым номером.

Миграций нет, переиндексация памяти не нужна, ручных шагов до и после кнопки нет. **Эта выкатка ещё долгая**:
образы и копия песочниц делаются в новом виде с нуля. Ускорение видно со следующего выпуска.

## Что изменилось для владельца (из v0.82.0)

- **Сервер скачивает только то, что изменилось.** Номер версии больше не попадает внутрь сборки образов — ни
  меткой, ни через `package.json`, — поэтому неизменённые слои (пакеты Node, системные пакеты песочницы) берутся
  из кэша и не скачиваются заново. Ожидаемо: скачивание ~1 минута вместо 4.
- **Копия папок песочниц переносит только изменения.** Изменившиеся файлы записываются заново, остальные —
  ссылки на прошлую копию, те же байты на диске. Кэши (pip, браузеры Playwright, Chrome для puppeteer) не
  копируются. Копий по-прежнему три. Ожидаемо: 1–2 минуты вместо 14, и время больше не растёт с объёмом папок.
- **Простой короче.** Пока бот остановлен, контрольные суммы считаются только по копии базы и ключей Google;
  старая копия только переименовывается, её файлы удаляются после запуска новой версии.
- **На GitHub тесты не гоняются дважды.** `main` сразу собирает релиз, если тот же код уже прошёл обе проверки
  на `develop`. На v0.82.0 это уже сработало: сборка 7 минут вместо 15.

Подробности, коды событий и ограничения — в описании v0.82.0 и в инструкции деплоя.

## Выкатка и установка

- Обычная выкатка кнопкой. По времени — как прежние: образы и копия песочниц делаются в новом виде с нуля.
- Свободное место: первая копия песочниц несжатая (~5,2 ГБ), на сервере свободно 56 ГБ.
